# my-c-learning

Репозиторий что бы повторить C.

## Задания

1. Калькулятор на switch

Программа спрашивает у пользователя два числа и операцию (+, -, *, /), выводит результат.

    Используй scanf для ввода.

    Через switch по символу операции.

    Обработай деление на ноль отдельным сообщением.

    Для деления используй double, а не int — иначе будет целочисленное деление.

Что тренирует: switch, scanf, приведение типов, if внутри case.
2. FizzBuzz с параметром

Пользователь вводит N. Программа печатает числа от 1 до N, но:

    кратные 3 → Fizz,

    кратные 5 → Buzz,

    кратные и 3, и 5 → FizzBuzz,

    иначе — само число.

    Реши через for.

    Потом перепиши через while — сравни, что читается лучше.

    Проверь порядок условий: почему if (n % 15 == 0) надо ставить первым?

Что тренирует: циклы, %, порядок ветвлений, printf с %d.
3. Угадай число

Программа «загадывает» число (просто константа в коде, например 42). Пользователь вводит догадки в цикле, программа говорит «больше»/«меньше», пока не угадает. В конце — сколько попыток понадобилось.

    Цикл while с условием «пока не угадал».

    Счётчик попыток — обычная int.

    Обработай случай, когда scanf вернул не 1 (ввели не число) — просто выйди из цикла.

Что тренирует: while, счётчики, проверка результата scanf, break.
4. Проверка простого числа

Пользователь вводит n > 1. Программа отвечает, простое ли оно.

    Перебор делителей от 2 до n-1 (потом оптимизируй до sqrt(n) — подключи math.h, не забудь -lm).

    Отдельно обработай n <= 1 — не простое.

    Сделай функцию int is_prime(int n), возвращающую 1 или 0. Вызови её из main.

Что тренирует: вынесение логики в функцию, return, ранний выход из цикла, math.h.
5. Сумма цифр и «перевёрнутое» число

Пользователь вводит целое положительное число. Программа выводит:

    сумму его цифр,

    число, записанное в обратном порядке (например, 1234 → 4321).

    Только арифметика: % 10 и / 10 в цикле.

    Отдельно подумай, что будет с числом, оканчивающимся на 0 (например, 120 → 21). Это нормально.

Что тренирует: while с изменением переменной, % и /, накопление результата.
6. Мини-меню с повторным запуском

Программа показывает меню:
text

1 - приветствие
2 - сложить два числа
3 - выйти

Считывает выбор, выполняет действие, снова показывает меню, пока не выберут 3.

    Внешний цикл do { ... } while (choice != 3);

    Каждый пункт — либо switch, либо отдельная функция.

    Неверный ввод (не 1/2/3) — сообщение и снова меню.

Что тренирует: do-while, switch, функции без аргументов и с аргументами, обработка «плохого» ввода.
